# Pochatox JinjaFrontend

Фронтенд-сервис для **Pochatox**, отвечающий за серверный рендеринг страниц с помощью **Jinja2** и работу как промежуточного слоя между браузером и backend API.

> Backend repository: [Pochatox/Core](https://github.com/Pochatox/Core)

## Описание

`JinjaFrontend` — это отдельный веб-сервис, который:

- рендерит HTML-страницы на сервере через **Jinja2**;
- принимает все входящие запросы от клиента;
- отправляет запросы к backend API;
- получает ответы от API и отображает их в интерфейсе;
- выступает как единая точка взаимодействия между браузером и backend.
